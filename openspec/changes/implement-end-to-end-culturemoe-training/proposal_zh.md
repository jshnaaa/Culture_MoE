# 实现端到端CultureMoE训练

## 概述
将当前的两阶段训练方法（LoRA预训练 + 冻结MoE训练）转换为统一的端到端训练方法，同时优化基础语言模型和MoE组件。

## 问题描述
当前的 `ft_culturemoe_from_base_gen.py` 实现采用了次优的方法：
1. 加载预训练基础模型 + 微调好的LoRA权重（合并后冻结）
2. 在上面添加MoE层，只训练MoE组件
3. 微调后的基础模型参数在MoE训练期间保持冻结

这种方法有几个局限性：
- **适应性有限**: 微调后的基础模型无法进一步适应MoE路由决策
- **集成不理想**: MoE层独立于微调后的基础模型表示进行训练
- **训练效率低**: 微调后基础模型的知识没有与文化专门化联合优化
- **性能差距**: 冻结微调模型通常比继续联合训练的性能要差

## 提议的解决方案
实现统一的端到端训练方法：
1. 从微调模型开始（加载并合并预训练的LoRA权重）
2. 将MoE层添加到微调模型架构中
3. 联合训练微调模型和MoE组件与文化目标
4. 使用梯度累积和混合精度来处理内存约束
5. 为微调模型与MoE组件应用不同的学习率（分层学习率）

## 优势
- **更好的性能**: 微调模型 + MoE的联合优化通常产生更优的结果
- **利用现有工作**: 基于已经微调的LoRA权重而不是从头开始
- **更好的集成**: MoE路由可以影响和适应微调模型表示
- **简化工作流**: 单一训练阶段而不是冻结参数训练
- **更灵活**: 在保持微调知识的同时更容易实验不同的架构组合

## 实现范围
此更改影响：
- `ft_culturemoe_from_base_gen.py` 中的训练方法
- 参数初始化和优化策略
- 内存管理和训练效率
- 评估和监控工作流

## 成功标准
- 端到端训练脚本成功从基础模型训练
- 训练收敛且损失曲线稳定
- 文化评估指标显示比两阶段方法有改进
- 内存使用在梯度累积下保持可管理
- 训练时间与当前方法相比合理
