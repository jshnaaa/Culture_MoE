# 文档更新规范

## 修改要求

### 要求：CultureMoE架构文档
系统文档应更新以反映联合训练模型架构和CSL损失函数设计。

#### 场景：联合训练模型架构
**给定** `culturemoe.md`文档文件
**当** 更新架构描述时
**则** 文档应描述联合LoRA+MoE训练方法
**且** 应解释基础LoRA和MoE专家层的同时优化
**且** 应记录共享专家和路由专家之间的关系
**且** 应包含架构图和组件描述

#### 场景：CSL损失函数文档
**给定** `culturemoe.md`文档文件
**当** 记录损失函数设计时
**则** 文档应包含CSL的数学公式
**且** 应描述三个CSL组件：
- L_culture_router用于路由专家文化专业化
- L_culture_share用于共享专家文化无关性
- L_culture_sr用于共享-路由表示解耦
**且** 应解释每个组件的设计目标
**且** 应包含数学符号和公式

#### 场景：模型组件文档
**给定** `culturemoe.md`文档文件
**当** 描述模型组件时
**则** 文档应描述JointLoRAMoEModel架构
**且** 应解释LoRA适配器与MoE层的集成
**且** 应记录专家路由机制和权重计算
**且** 应描述共享专家功能和文化无关目标
**且** 应解释路由专家和共享专家之间的交互

#### 场景：训练流水线文档
**给定** `culturemoe.md`文档文件
**当** 记录训练过程时
**则** 文档应描述联合训练方法
**且** 应解释LoRA和MoE组件的差异学习率
**且** 应记录CSL损失集成和参数配置
**且** 应包含训练脚本使用示例和参数指导
**且** 应描述与现有简化CultureMoE方法的关系

### 要求：损失函数数学公式
文档应包含CSL损失函数的全面数学描述。

#### 场景：数学符号
**给定** CSL损失函数文档
**当** 描述数学公式时
**则** 文档应定义所有符号和记号：
- B：批次大小
- i, j：样本索引
- cul_i：样本i的文化标签
- wr_i：样本i的路由专家权重向量（K维）
- es_i：样本i的共享专家输出向量
- er_i：样本i的路由专家融合输出向量
- sim(x, y)：余弦相似度函数
**且** 应在整个文档中使用一致的数学记号

#### 场景：损失组件公式
**给定** CSL损失函数文档
**当** 展示数学公式时
**则** 文档应包含每个组件的精确公式：
- L_culture_router与成对相似性计算
- L_culture_share与文化无关目标
- L_culture_sr与解耦机制
**且** 应解释平均和归一化过程
**且** 应描述与总损失计算的集成

#### 场景：设计理念
**给定** CSL损失函数文档
**当** 解释设计决策时
**则** 文档应解释三组件设计的动机
**且** 应描述CSL如何解决以前方法的限制
**且** 应解释文化专业化和表示学习之间的关系
**且** 应讨论专业化和泛化之间的平衡

### 要求：配置和使用文档
文档应提供CSL配置和使用的清晰指导。

#### 场景：参数配置
**给定** 训练配置文档
**当** 描述CSL参数时
**则** 文档应记录`USE_CULTURE_LOSS=csl`选项
**且** 应解释从`new`到`csl`的默认参数更改
**且** 应描述与其他文化损失模式的关系
**且** 应为不同用例提供参数选择指导

#### 场景：模型要求
**给定** CSL使用文档
**当** 描述系统要求时
**则** 文档应指定CSL的模型输出要求
**且** 应记录专家输出提取能力的需求
**且** 应解释与不同模型配置的兼容性
**且** 应描述不满足要求时的回退行为

#### 场景：性能考虑
**给定** CSL实现文档
**当** 描述性能特征时
**则** 文档应记录计算开销预期
**且** 应提供批次大小考虑的指导
**且** 应描述内存使用影响
**且** 应包含性能优化建议
