# CultureMoE 模型评估系统实现提案

## 概述

本提案旨在为 CultureMoE 项目实现一套完整的模型评估系统，使研究人员能够在保留的测试集上对训练好的模型进行标准化测试，并从保存的训练参数中正确重建完整模型。

## 为什么需要这个系统

CultureMoE 训练流程能够成功训练模型，但缺乏系统化的评估能力。没有合适的评估工具，研究人员无法：
- 在保留的测试集上验证模型性能
- 客观地比较不同模型配置的效果
- 在不同环境中重现评估结果
- 确保测试集隔离和评估完整性

本提案通过实现一套与训练流程同样严格的综合评估系统来解决这些问题。

## 问题陈述

目前，CultureMoE 训练流程（`run_simplified_culturemoe.sh`）成功训练模型并保存最佳性能检查点，但缺少专门的评估系统来：

1. **正确加载训练好的模型**：从保存的 LoRA 权重、MoE 权重和配置文件重建完整的 CultureMoE 模型
2. **在测试集上评估**：使用 8:1:1 数据集划分在未见过的测试数据上评估模型
3. **标准化评估指标**：提供一致的准确率、精确率、召回率和 F1 分数测量
4. **支持可重现研究**：实现不同模型配置的系统化比较

## 目标

### 主要目标
- 创建 `run_eval_simplified_culturemoe.sh` 脚本，支持模型输出目录和基座模型参数
- 实现 `eval_simplified_culturemoe.py` 用于模型加载和评估
- 支持所有训练好的模型配置（不同主干、MoE 设置、LoRA 配置）
- 生成包含多项指标的综合评估报告

### 次要目标
- 保持与现有训练流程输出的兼容性
- 遵循项目的代码风格和架构约定
- 提供清晰的错误处理和用户反馈

## 技术方案

### 模型加载策略
1. **基座模型加载**：从指定路径加载原始基座模型（LLaMA/Qwen）
2. **配置重建**：解析 `simplified_culturemoe_config.json` 重建模型架构
3. **权重整合**：
   - 从 `lora_weights/` 目录加载 LoRA 权重
   - 从 `moe_weights.pt` 文件加载 MoE 权重
   - 使用 SimplifiedCultureMoEAdapter 将权重与基座模型合并
4. **模型验证**：验证模型架构与训练配置匹配

### 数据集处理
1. **划分文件加载**：从保存的 `.pkl` 划分文件读取测试集索引
2. **数据预处理**：应用与训练相同的分词和格式化
3. **批处理**：使用高效的批处理来处理大型测试集

### 评估指标
1. **分类指标**：文化分类任务的准确率、精确率、召回率、F1 分数
2. **生成指标**：生成任务的答案提取和比较
3. **详细报告**：适当情况下的每类指标和混淆矩阵

## 风险和缓解措施

### 技术风险
- **模型加载复杂性**：CultureMoE 模型具有 LoRA + MoE 组件的复杂架构
  - *缓解*：重用现有的 SimplifiedCultureMoEAdapter 加载逻辑
- **内存约束**：大型模型可能在评估期间超出可用 GPU 内存
  - *缓解*：实现批处理和内存优化技术
- **配置兼容性**：不同的训练配置可能需要不同的加载方法
  - *缓解*：综合配置验证和错误处理

### 项目风险
- **代码重复**：重复现有训练逻辑的风险
  - *缓解*：参考但不修改现有代码，创建新的独立模块
- **测试限制**：无法在没有 GPU 环境的情况下本地测试
  - *缓解*：专注于代码审查和逻辑验证，设计健壮性

## 技术架构

### 模型重建流程
```
基座模型 → LoRA 整合 → MoE 整合 → 完整 CultureMoE 模型
    ↓           ↓            ↓              ↓
从基座路径   从 lora_weights/ 从 moe_weights.pt  准备评估
  加载       目录加载        文件加载
```

### 数据加载架构
```
训练输出目录
├── config.json (训练配置)
├── data_split_8_1_1.pkl (数据集划分)
├── best_simplified_culturemoe/
│   ├── lora_weights/ (LoRA 参数)
│   ├── moe_weights.pt (MoE 参数)
│   └── simplified_culturemoe_config.json (模型配置)
└── training.log (训练历史)
```

### 评估框架
```
模型 + 测试数据 → 批处理 → 指标计算 → 报告生成
      ↓             ↓         ↓          ↓
   分词和格式化   内存高效    多指标      格式化
                GPU 利用    评估        输出
```
